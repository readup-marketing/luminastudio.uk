# luminastudio.uk

Static single-page site for Lumina Studios, served by GitHub Pages (custom domain in `CNAME`).

## Booking link
Every "Book your free taster" button points to `https://calendly.com/luminastudiouk/lumina-free-taster`.
The earliest taster times are about two weeks out, because the taster pack is posted first.
After a taster booking or a payment, send people to `https://luminastudio.uk/thankyou.html`.
